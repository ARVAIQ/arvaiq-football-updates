# ARVAIQ Football 2.1.0

## Product integration

- Integrates the new ARVAIQ intelligence foundation into Football.
- Football and Admin now follow independent release/version streams.
- Adds Shadow intelligence support without allowing Shadow models to influence user-facing decisions.
- Keeps BTTS in HOLD/REVIEW.
- Keeps Asian Handicap and Team Totals blocked until exact line context is available.
- Protected coefficients, training data, private model files and global history remain server-side.
- Preserves compatibility with the legacy 2.0.7 GitHub latest-release updater for this transition release.

## Release channel

This release is distributed through the official ARVAIQ Football update channel.
