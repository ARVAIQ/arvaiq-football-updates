ARVAIQ Football 2.0.7 — publicação automática pelo GitHub Actions

Este pacote evita preencher a página de Releases manualmente.

1. Extrai TODO o conteúdo deste ZIP diretamente para:
   D:\ARVAIQ_DEV\arvaiq-football-updates

2. Abre esse repo no GitHub Desktop.

3. Deves ver:
   - .github/workflows/publish-2.0.7.yml
   - release-assets/v2.0.7/ARVAIQ.Football.-.Setup.exe
   - release-assets/v2.0.7/ARVAIQFootball.exe
   - os dois .sha256
   - RELEASE_NOTES_2.0.7.md
   - .gitignore

4. Commit:
   Publish ARVAIQ Football 2.0.7

5. Push origin.

Depois do push, o GitHub Actions cria automaticamente a Release pública v2.0.7
e anexa os quatro assets com os nomes esperados pelo updater.
