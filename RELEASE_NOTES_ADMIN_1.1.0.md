# ARVAIQ Admin 1.1.0

- Substitui o seletor nativo de Modelos por um acordeão moderno na barra lateral.
- Agrupa as áreas de inteligência, treino, validação, promoção e jogadores.
- Abre todas as áreas de Modelos dentro da janela principal do Admin.
- Adiciona uma barra superior com versão, utilizador e estado dos serviços.
- Move API e sessão OWNER da visão geral para Definições.
- Transforma Telemetria num painel operacional com estados, latência, última leitura e erros recentes.
- Mantém a exportação Excel apenas dentro do Histórico.
- Preserva o atualizador interno exclusivo do Admin: sem Setup e sem iniciar o Football.
