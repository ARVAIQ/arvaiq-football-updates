# ARVAIQ Admin 1.0.1

- Nova janela de login com o mesmo tamanho e comportamento explícito do Football.
- Opção para guardar a palavra-passe de forma cifrada pelo Windows, sem iniciar sessão automaticamente.
- Telemetria integrada num separador próprio do Admin, sem depender de Excel.
- Área Modelos simplificada com um seletor suspenso à esquerda, em vez de vários botões no topo.
- Football e respetivo canal de atualização permanecem inalterados.
